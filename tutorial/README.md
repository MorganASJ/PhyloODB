# PhyloODB Tutorial

This directory contains the worked mammal core dataset tutorial and its
companion shell script.

- [Chimpanzee-centred mammal core tutorial](chimp_mammal_core_example.md) –
  copy-paste friendly walkthrough using serial `run` commands.
- [Rich selector examples tutorial](chimp_mammal_core_rich_examples.md) –
  duplicate walkthrough with extra selector preset and saved accession set examples.
- [Companion shell script](chimp_mammal_core_example.sh) – the same workflow as
  an editable Bash script.

For shorter setup instructions, start with
[the quickstart](../docs/QUICKSTART.md). For the full user guide, see
[the manual](../docs/MANUAL.md).
